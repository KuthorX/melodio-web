Lecteur d'albums local dans le navigateur. Les fichiers audio, les images et les réglages restent dans le navigateur courant.

## Utilisation

```bash
npm run dev
```

Ouvrez `http://localhost:4173`, puis choisissez un dossier contenant les titres et les images. Les réglages permettent de choisir l'image, le début et la fin d'écoute de chaque titre. La configuration est conservée dans le cache du navigateur.

Raccourcis : Espace lecture/pause, ←/→ titre, ↑/↓ thème, `G` réglages, `M` mouvement, `H` mode immersif.
