브라우저에서 실행되는 로컬 앨범 플레이어입니다. 오디오, 이미지, 설정은 현재 브라우저에만 보관됩니다.

## 사용법

```bash
npm run dev
```

`http://localhost:4173`을 열고 오디오와 이미지가 있는 폴더를 선택하세요. 곡마다 이미지, 감상 시작점, 감상 종료점을 설정할 수 있으며 설정은 브라우저 캐시에 저장됩니다.

단축키: 스페이스 재생/일시정지, ←/→ 곡 변경, ↑/↓ 테마, `G` 트랙 설정, `M` 모션, `H` 몰입 모드.
