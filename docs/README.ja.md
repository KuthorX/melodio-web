ブラウザーで動くローカルアルバムプレーヤーです。音声、画像、設定は現在のブラウザー内に保存されます。

## 使い方

```bash
npm run dev
```

`http://localhost:4173` を開き、音声と画像が入ったフォルダーを選びます。曲ごとに画像、試聴開始位置、試聴終了位置を設定できます。設定はブラウザーのキャッシュに保存されます。

ショートカット：スペース 再生/一時停止、←/→ 曲変更、↑/↓ テーマ、`G` 曲目設定、`M` モーション、`H` 没入モード。
