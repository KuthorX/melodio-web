Локальный музыкальный проигрыватель в браузере. Аудио, изображения и настройки остаются в текущем браузере.

## Использование

```bash
npm run dev
```

Откройте `http://localhost:4173` и выберите папку с аудио и изображениями. Для каждого трека можно задать изображение, начало и конец прослушивания. Настройки сохраняются в кэше браузера.

Клавиши: Пробел воспроизведение/пауза, ←/→ трек, ↑/↓ тема, `G` настройки, `M` движение, `H` иммерсивный режим.
