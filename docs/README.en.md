A local album player for the browser. Audio, images, and settings stay in the current browser.

Screenshots: see the Chinese README for the full PC, immersive, mobile, audition-range, and themed-dropdown gallery.

## Usage

```bash
npm run dev
```

Open `http://localhost:4173`, then choose or drop a folder containing audio and images. Track settings support per-track artwork, preview start, and preview end. The configuration is saved in the current browser cache.

Shortcuts: Space play/pause, Left/Right change track, Up/Down change skin, `G` track settings, `M` motion, `H` immersive mode.
