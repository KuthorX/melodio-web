Reproductor de álbumes local para el navegador. El audio, las imágenes y los ajustes permanecen en el navegador actual.

## Uso

```bash
npm run dev
```

Abre `http://localhost:4173` y elige una carpeta con canciones e imágenes. Los ajustes permiten elegir imagen, inicio y final de escucha para cada pista. La configuración se guarda en la caché del navegador.

Atajos: Espacio reproducir/pausar, ←/→ pista, ↑/↓ tema, `G` ajustes, `M` movimiento, `H` modo inmersivo.
